Proyecto Cursos de Idiomas

Este proyecto corresponde al backend de la aplicación "CursosIdiomas". En él se desarrollaron las funcionalidades principales necesarias para gestionar cursos de idiomas, usuarios, inscripciones y acceso a los recursos de aprendizaje.

Qué se hizo

- Se creó la estructura base del proyecto backend.
- Se implementaron los modelos de datos para cursos, estudiantes, profesores e inscripciones.
- Se desarrollaron los controladores y servicios necesarios para exponer las operaciones CRUD (crear, leer, actualizar, eliminar).
- Se configuró la conexión a la base de datos y la persistencia de la información.
- Se añadió la simulación de pago para las inscripciones, sin integración de pasarelas reales.
- Se añadieron validaciones básicas para los datos de entrada y manejo de errores.
- Se dejó preparada la aplicación para ser desplegada o ejecutada localmente.

Componentes principales

- Modelo de cursos: permite gestionar información de los cursos de idiomas, niveles y descripciones.
- Modelo de usuarios: administra estudiantes y profesores con los datos necesarios para cada rol.
- Modelo de inscripciones: controla la relación entre usuarios y los cursos en los que participan.
- Endpoints de API: ofrecen acceso a las funcionalidades del backend mediante peticiones HTTP.

Objetivo

El objetivo del proyecto es proporcionar una API backend funcional que sirva como base para una aplicación de gestión de cursos de idiomas, permitiendo la administración de contenido y usuarios de manera centralizada.
